# Daya Guest Manager

Crée une application web professionnelle appelée « LE DAYA HOTEL MANAGER », destinée à la gestion complète de LE DAYA Guest House à Port-Gentil, Gabon.



L'application doit être en français et utiliser le FCFA/XAF comme devise.



Je veux une véritable application fonctionnelle, pas une simple maquette.



Elle doit être responsive et fonctionner correctement sur ordinateur, tablette et téléphone Android.



Crée une architecture propre et évolutive permettant d'ajouter ultérieurement d'autres chambres ou d'autres établissements.



Commence par créer :



1. Une page de connexion.

2. Un tableau de bord.

3. Une navigation latérale professionnelle.

4. Une base de données persistante.

5. Un système d'utilisateurs et de rôles.

6. Un module de gestion des chambres.

7. Un module de gestion des clients.

8. Un module de réservations.

9. Un module de caisse.

10. Un module de facturation.

11. Un module PCS (Pièces de Caisse).

12. Un module de dépenses.

13. Un module de taxe de séjour.

14. Un module de rapports.

15. Une page de paramètres.



Pour l'instant, crée correctement l'architecture générale et la base de données avant d'ajouter toutes les fonctionnalités avancées.



L'établissement possède actuellement 5 chambres :



- Standard 1 : 25 000 FCFA/nuit

- Standard 2 : 25 000 FCFA/nuit

- Standard 3 : 25 000 FCFA/nuit

- VIP : 35 000 FCFA/nuit

- Studio : 50 000 FCFA/nuit



La taxe de séjour est de 1 000 FCFA par nuitée et par chambre.



Le montant de la taxe doit être configurable dans les paramètres administrateur.



Ne mets pas de données fictives à la place des fonctionnalités réelles.



Avant de commencer à coder, analyse cette architecture et construis une base solide permettant d'ajouter progressivement les fonctionnalités.
